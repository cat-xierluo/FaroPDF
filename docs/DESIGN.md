# FaroPDF 设计系统

> Last updated: 2026-06-02

## 设计目标

FaroPDF 是一个 PDF 阅读器，不是 Markdown 编辑器，也不是全能文件管理器。第一视觉永远是 PDF 页面。工具栏、侧边栏、批注列表和 OCR 面板都要服务于阅读、定位和交付。

关键词：

- 清亮：浅色纸面、低噪音工具栏、克制线条。
- 快速：打开即可读，搜索和缩略图逐步可用。
- 专业：适合法律材料、长卷宗、扫描件和批注整理。
- 可回退：任何会改变 PDF 的操作都清楚展示输出和影响。

## 视觉原则

- 主背景使用接近纸张的暖白或浅灰，不使用深色科技感大渐变。
- PDF 页面使用真实白色纸面和细边界，页面之间保留足够间距。
- 强调色只用于当前页、搜索命中、批注激活和主要操作。
- 工具栏默认轻量图标化，复杂工具进入面板或浮层。
- 不使用营销式首屏，不做大面积 hero；启动后就是阅读器。

## 布局

```text
┌──────────────────────────────────────────────┐
│ Title Bar / Main Toolbar                     │
│ Summary · Page Manager · View · Mode · Search│
├──────────────┬───────────────────────────────┤
│ Utility Pane │ PDF Pages / Task Workspace    │
│ Summary/View │ Virtual viewport or page grid  │
│ Settings     │                               │
├──────────────┴───────────────────────────────┤
│ Status Bar: page / zoom / text layer / dirty │
└──────────────────────────────────────────────┘
```

FaroPDF 的页面逻辑参考 PDF Expert 的信息架构，但不照搬其品牌、图标或视觉样式：

- 阅读态以中央 PDF 页面为主，不常驻右侧 Inspector。
- 左侧是按需工具区：文档摘要、视图设置、设置面板共用同一区域。
- 批注、OCR、导出、填写和签名使用第二行上下文工具条。
- 页面管理进入独立页面网格工作台，替换阅读区，而不是塞进侧栏。
- 搜索优先放在顶部工具栏，命中列表后续可用轻量浮层或临时面板。
- 当前 `feat/pdf-expert-shell-ia` 只是信息架构草案，不视为 UI 已完成；后续必须继续做视觉密度、按钮分组、空态、真实缩略图和多模式细节。

### Toolbar

- 左侧：文档摘要、页面管理、视图设置。
- 中间：打开 PDF、另存、页码、缩放、单页/连续/双页。
- 模式区：批注、导出、填写和签名、OCR。
- 右侧：全文搜索和设置。
- 图标优先，必要时使用短标签。
- 批注、导出、表单和 OCR 工具条只在进入对应模式后显示，不常驻挤压阅读区。

### Utility Pane

- 默认显示文档摘要，可切换书签、大纲、批注列表和缩略图。
- 宽度控制在 280px 到 320px，可折叠。
- 缩略图标记当前页、搜索命中、批注存在和 OCR 状态。
- 大卷宗下缩略图必须懒加载。
- 视图设置进入同一左侧区域，提供单页/双页、无拆分/垂直/水平等阅读选项。
- 设置页可临时占用左侧区域，承载 OCR provider、保存策略和隐私确认。

### Reader

- 支持连续、单页、双页和适合宽度。
- 当前页保持清晰边界，但不使用厚重阴影。
- 选中文本时展示轻量批注浮条。
- 搜索命中使用半透明高亮，当前命中使用更明显边框。

### Task Workspaces

复杂任务优先进入任务模式或独立工作台，不同时常驻多个复杂面板：

- 搜索：顶部关键词输入；命中列表和上下文后续用轻量结果层。
- 批注：上下文工具条负责高亮、下划线、删除线、笔记、图章和签名；批注列表放入文档摘要的批注列表页。
- OCR：上下文工具条负责增强扫描、拆分页面、裁剪页面、清除空白边、OCR 识别、质量检查和双层 PDF 输出；参数由设置页管理。
- 页面：独立网格工作台负责插入、旋转、复制、粘贴、摘录、删除、重排和预览。
- 表单：上下文工具条负责文本、签名、日期、勾号、叉号、图章、图片和扁平化导出；字段列表后续按需显示。
- 导出：区分格式转换和交付工具。格式转换包括转 Word、Excel、PowerPoint、文本和图片；交付工具包括水印、页码、Bates、压缩、批注摘要和扁平化。

## 字体

| 角色 | 建议 |
| --- | --- |
| UI | system-ui, PingFang SC, Microsoft YaHei UI |
| PDF 页内容 | 由 PDF 原始字体决定 |
| 状态栏/页码 | ui-monospace, SF Mono, Menlo |
| 批注正文 | system-ui, PingFang SC |

原则：

- UI 字号保持 12px 到 14px。
- 状态栏文字弱化，避免抢阅读注意力。
- 批注摘要和搜索上下文要可读，不要使用过小字号。

## 颜色角色

| Token | 用途 |
| --- | --- |
| `--bg` | 应用背景 |
| `--surface` | 工具栏、侧栏、面板 |
| `--paper` | PDF 页面纸面 |
| `--border` | 分隔线、页面边界 |
| `--fg` | 主要文字 |
| `--muted` | 次要文字 |
| `--accent` | 当前页、激活工具、主操作 |
| `--highlight` | 搜索命中和文本高亮 |

批注颜色允许多色，但必须限制在批注语义内，不扩散为全应用主题色。

## 批注交互

- 选择文本后出现浮动批注条：高亮、下划线、删除线、备注。
- 批注工具栏提供矩形、箭头、文本框、手写、图章。
- 批注列表按页码排序，可按颜色、类型和关键词筛选。
- 删除批注要可撤销。
- 批注摘要导出时保留页码、类型、内容和上下文。

## OCR 交互

- 无文字层时在状态栏和 OCR 面板提示，不弹出阻塞对话框。
- OCR 后端选择放在 OCR 面板内。
- 联网 OCR 必须展示隐私提示和确认操作。
- 任务运行中展示进度、后端、页码范围和输出路径。
- OCR 完成后提供打开输出 PDF、搜索抽查和替换当前阅读文件三个动作。

## 页面整理交互

- 页面整理进入独立网格视图，避免在普通阅读时误删页面。
- 删除、重排、旋转支持撤销。
- 导出按钮明确显示“另存为新 PDF”。
- Bates 编号和页码添加必须提供预览和位置选择。

## 与 Folia 的边界

FaroPDF 不复用 Folia 的 Markdown 编辑布局：

- 不提供 Markdown 源码模式。
- 不提供 Word 纸张预览。
- 不提供 HTML 导出预览。
- 不把 PDF 阅读作为 Folia 的右侧面板。

可以复用的只有设计经验：清亮、克制、内容优先、按需加载。
