# FaroPDF 任务清单

> 待处理任务、缺陷修复、技术债清理和未归属 Roadmap 的工作项。

## 待处理

### ISS-001 初始化 Tauri 应用脚手架

- 优先级：P0
- 类型：工程基础
- 状态：待处理
- 目标：创建 Tauri v2 + React + TypeScript + Vite 应用，并补齐基础测试、类型检查、Lint、构建脚本。
- 验收：本地可启动空壳应用，`typecheck`、测试和构建命令可运行。

### ISS-002 PDF.js 快速阅读底座

- 优先级：P0
- 类型：阅读核心
- 状态：待处理
- 目标：接入 PDF.js，支持打开本地 PDF、worker 渲染、页面虚拟化、缩放、页码跳转和连续阅读。
- 验收：几百页 PDF 打开后只渲染可见页附近，滚动和缩放不卡住主界面。

### ISS-003 文本层检测与全文搜索

- 优先级：P0
- 类型：检索
- 状态：待处理
- 目标：检测文字层，建立按需搜索索引，支持命中列表、当前页高亮和上下一个命中。
- 验收：可搜索 PDF 能稳定命中关键词；纯扫描 PDF 显示 OCR 提示。

### ISS-004 批注 sidecar 模型

- 优先级：P0
- 类型：批注
- 状态：待处理
- 目标：建立 `PdfAnnotation` 模型和 sidecar 持久化策略，支持高亮、下划线、删除线、备注、文本框、形状、手写和图章。
- 验收：批注可新增、编辑、删除、列表展示、点击跳转，并能导出摘要。

### ISS-005 PDF 导出与批注扁平化

- 优先级：P0
- 类型：导出
- 状态：待处理
- 目标：使用 pdf-lib 将批注和页面操作导出为新 PDF，默认不覆盖原文件。
- 验收：导出的 PDF 保留阅读批注和页面操作结果；原始 PDF 不变。

### ISS-006 页面整理工作台

- 优先级：P0
- 类型：页面管理
- 状态：待处理
- 目标：支持旋转、删除、重排、插入、提取、合并和添加页码/Bates 编号。
- 验收：页面操作可预览、撤销，并输出新 PDF。

### ISS-007 OCR bridge

- 优先级：P0
- 类型：OCR
- 状态：待处理
- 目标：建立 OCR 任务模型，优先连接本地 Legal Skills / `ocrmypdf`，预留 PaddleOCR 和 MinerU 后端。
- 验收：纯扫描 PDF 可触发 OCR 任务，生成双层 PDF 并展示质量检查结果。

### ISS-008 表单填写与签署

- 优先级：P1
- 类型：表单
- 状态：待处理
- 目标：支持 AcroForm 字段识别、填写、签名图片/手写签名和扁平化导出。
- 验收：常见 PDF 表单可填写并导出为不可编辑提交版。

### ISS-009 设计系统落地

- 优先级：P1
- 类型：UI
- 状态：待处理
- 目标：按 `docs/DESIGN.md` 实现清亮阅读布局、克制工具栏、左侧缩略图/目录、右侧批注/搜索/OCR 面板。
- 验收：界面不复用 Folia 的 Markdown 编辑布局，PDF 页面始终是主视觉。

### ISS-010 法律材料隐私与联网 OCR 提示

- 优先级：P0
- 类型：安全
- 状态：待处理
- 目标：联网 OCR 前提供明确提示，记录后端、文件范围、输出路径，不在日志中泄露敏感内容。
- 验收：任何云端 OCR 都需要用户主动确认。
