# Search Module

负责文字层检测、按需全文索引、命中列表和页面高亮。

搜索不应在打开文件时同步扫描全卷，后续实现需按页分批索引。

当前第一版：

- `textSearchService` 管理内存搜索会话、页文本缓存、命中列表、当前命中和 OCR 提示。
- `useTextSearchController` 连接阅读器页文本读取、命中跳页和 OCR 模式入口。
- Toolbar 搜索结果层展示命中数量、上下文片段、上下一个命中和继续索引入口。
- Reader 区只展示轻量当前命中标记；真实 PDF text-layer 几何高亮留给阅读渲染深化。
- 不持久化搜索词历史，不写入真实文件名。
