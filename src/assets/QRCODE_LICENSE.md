# 微信公众号二维码占位图说明

## 当前文件

- `wechat-qrcode.png`（67 字节，1×1 像素，8-bit grayscale）

## 用途

用于 ISS-023（关于页面与作者页）的「作者卡」占位展示，**不包含任何真实公众号信息**，仅作为视觉占位存在。

## 后续替换

正式上线前，作者需要：

1. 准备真实微信公众号二维码图片（推荐 PNG / JPG，正方形 240×240 像素以上）。
2. 把图片放到 `src/assets/` 目录下（建议保留文件名 `wechat-qrcode.png`）。
3. 在 PR 描述里说明替换前后的差异；通过 `git diff --stat src/assets/` 确认仅变更这一张图。
4. 如果是 iOS / Android 二维码，统一保留公众号入口指向同一微信号；不要在仓库内提交任何账号 / 密码 / Token / 私钥。

## 风险与边界

- 仓库**不**接受包含真实账号、密码、Token 或个人敏感信息的二维码。
- 二维码图片受版权与平台规则约束：仅使用项目作者本人拥有或经授权的二维码。
- 如果需要更换占位图（例如改用 Notion / GitHub Sponsors 等其他联系方式），保留本 LICENSE 文件、更新本说明即可。
